Scribe is a lightweight, fast, cross platform email program. It features an easy to use interface, split view of folders and items, has an address book and calendar, and handles attachments, signatures, and drag and drop. It can be installer as a Desktop client or used in a portable USB install. Settings and libraries can be stored with the executable. It supports bayesian spam filtering and includes lots of tools for importing and exporting data in standard and popular formats.
