Printing

Printing
Print support is provided in Scribe for Email, Contacts and the Calendar View. The printer settings used for printing are under the menu File -> Print Setup. And the margin and Font settings are under File -> Page Setup.

HTML print support is available but it's converted at screen resolution into a bitmap and that is printed.

Scripted Printing
You can configure a filter to print every mail that matches some user specified criteria.

Also there is support for printing files from the command line.
