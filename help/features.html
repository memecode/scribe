Feature Support

All Versions
  • Protocols:
    • POP3, Auth types:
      • LOGIN
    • IMAP4 (Fetch or Full), Auth types:
      • LOGIN
      • NTLM (M$ exchange)
    • SMTP, Auth types:
      • Normal-none
      • LOGIN (ESMTP)
    • SOCKS5 support for all socket connections, Auth:
      • LOGIN
    • Calendaring over HTTP
      • LOGIN
  • User interface:
    • Split view of folders and items
    • Status pane containing:
      • List of accounts
      • Progress of email transfer
      • Colour coded transaction log
    • Mail preview pane
    • Resizable mail windows containing:
      • Full reflow text composition/display control
      • Collapsible panes for To: and From:
      • Auto-name lookup for recipient entry
      • List of attachments
      • Original internet headers
    • Colouring and labeling of email.
    • Absolutely safe display of HTML.
    • Substring match item filter for main window list.
    • Find window with most of the usual options.
    • Threaded view of email.
  • Email:
    • Reply, Reply All and Forward (with and without attachments).
    • Signatures (can include runtime customizations).
    • Multiple attachments and MIME typing (Moving email between folders doesn't require moving the attachment on disk).
    • Smart wrapping of quoted email on reply.
    • Bayesian Spam Filter captures ~98% of spam.
  • Contacts:
    • Multiple emails per contact.
    • Work and Home address/phone/IM.
    • Plug-ins can associate with certain Contacts only.
    • Timezone and display of Contact's local time.
    • Custom fields.
  • Calendaring:
    • Multiple day events.
    • Alarms.
    • Free/Busy information for shared calendars.
    • Week/Month/Year views.
  • Security:
    • Folder based permissions.
    • Safe from any virus.
  • Other:
    • All objects export their fields via a DOM, which is scriptable.
    • Cross platform, runs on Windows, MacOSX and Linux.
    • Printing support.
    • Unicode support with missing glyph substitution.
    • Drag and drop most objects.
    • Imports and Exports to most common email/PIM standard text file formats.
    • Administrator options for site installation.
    • Some add-on plug-ins to extend the functionality.
  • Filtering system
    • Filter on any field of the email
    • Possible actions to take:
      • Move to folder
      • Delete
      • Print
      • Play Sound
      • Open
      • Execute Process using email as input. This allows you to use programs to automatically process an email.
      • Set Colour
      • Set Read
      • Set Label
      • Empty Folder
      • Delete As Spam
    • User initiated filtering of email in a folder.
  • Multiple incoming mail accounts
    • Each account has it's own identity, which is used when replying to email received on that account.
